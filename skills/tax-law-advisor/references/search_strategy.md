# 검색 전략 가이드 (references)

법령 조문은 OPEN API를, 상담사례·유권해석은 웹 조회를 쓰는 **하이브리드** 전략.

## 1. 국가법령정보시스템 (법령 조문) — OPEN API 우선

- OPEN API 신청: https://open.law.go.kr → 발급받은 OC 키를 `LAW_OC` 환경변수에 설정
- 스크립트: `scripts/law_search.py`
- API가 안 되면 웹 조회 폴백:
  - 법령 검색/본문: https://www.law.go.kr → 법령명·조문 조회
  - WebFetch 로 `https://www.law.go.kr/법령/부가가치세법` 형태 접근 가능

### 세목별 주요 법령
| 세목 | 법령 | 자주 보는 조문 예시 |
|------|------|---------------------|
| 부가가치세 | 부가가치세법 / 시행령 / 시행규칙 | 매입세액 공제·불공제, 세금계산서, 영세율/면세 |
| 법인세 | 법인세법 / 시행령 | 손금산입·불산입, 접대비, 감가상각, 세액공제 |
| 소득세 | 소득세법 / 시행령 | 필요경비, 원천징수, 기타소득 |
| 공통 | 국세기본법, 조세특례제한법 | 가산세, 경정청구, 신고기한 |

## 2. 상담사례 · 유권해석 (선례) — 웹 조회

### (a) 국세법령정보시스템 taxlaw.nts.go.kr
- 해석사례(질의회신), 판례, 예규 검색
- WebSearch 쿼리 예: `site:taxlaw.nts.go.kr 매입세액 불공제 접대비`
- 검색 결과 URL을 WebFetch로 열어 요지/회신 확인

### (b) 홈택스 인터넷상담 사례 hometax.go.kr
- 국민신문고/인터넷상담 공개 사례
- 로그인 없이 열리는 공개 상담사례 위주로 확인

### (c) 법령해석례 (OPEN API `interp` 서브커맨드)
- 법제처·기관 유권해석은 OPEN API `target=expc` 로도 검색 가능
- `python3 scripts/law_search.py interp "<키워드>"`

## 3. 검색 팁
- 쟁점 키워드를 2~3개 조합 (예: "부가세 + 매입세액 + 접대비")
- 법령은 **정확한 조번호**까지, 사례는 **회신일자·기관**까지 기록해 신뢰도 표시
- 개정 잦은 세법 특성상 **시행일자** 반드시 확인
- 상충하는 사례가 있으면 최신 것 우선하되, 둘 다 제시하고 차이를 설명

## 4. 답변 시 면책 (항상)
